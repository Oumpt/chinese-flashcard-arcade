# 🎮 คู่มือนักพัฒนาและการปรับแต่ง: ระบบ Flashcard & Game ภาษาจีนสไตล์เรโทร 8-bit

ยินดีต้อนรับสู่คู่มือการพัฒนาของระบบสื่อการเรียนรู้คำศัพท์ภาษาจีนย้อนยุค **Retro-Modern Chinese Flashcard & Arcade Games** โปรเจกต์นี้เขียนขึ้นด้วยภาษาเว็บพื้นฐาน (Pure HTML, Vanilla CSS และ Vanilla JavaScript) โดยไม่มีเฟรมเวิร์ก เพื่อให้ง่ายต่อการศึกษา พัฒนาต่อยอด และนำไปปรับใช้ในชั้นเรียน

## ⚙️ วิธีการใช้งานและการเปิดโปรเจกต์ (How to Run)

เนื่องจากโปรเจกต์นี้เป็นแอปพลิเคชันแบบ **Static Client-side** 100% จึงไม่ต้องใช้การติดตั้งฐานข้อมูลหรือเซิร์ฟเวอร์หลังบ้าน:
1. **รันบนเครื่องภายใน (Local)**: เพียงดับเบิ้ลคลิกไฟล์ `index.html` เพื่อเปิดด้วยเบราว์เซอร์ยุคปัจจุบันได้ทันที (แนะนำ Google Chrome หรือ Microsoft Edge)
2. **การเผยแพร่แบบออนไลน์ (Deployment)**: สามารถนำไฟล์ทั้งหมดในโฟลเดอร์นี้อัปโหลดขึ้นโฮสติ้งฟรีได้โดยตรง เช่น **GitHub Pages**, **Vercel** หรือ **Netlify** เพื่อสร้างลิงก์เว็บไซต์ออนไลน์ให้ผู้เรียนเข้าถึงจากโทรศัพท์มือถือหรือแท็บเล็ตได้ทุกที่ทุกเวลา

## ✍️ วิธีเพิ่ม/แก้ไขคำศัพท์และหมวดหมู่ (How to Edit Vocabularies)

คลังข้อมูลคำศัพท์ทั้งหมดเก็บอยู่ในตัวแปร `vocabData` ที่ด้านบนสุดของไฟล์ [script.js](file:///d:/PtforWork/169/จีน/Flashcard_Chinese/script.js) (เริ่มที่ประมาณบรรทัดที่ 4) คุณสามารถเพิ่มหมวดหมู่หรือคำศัพท์ใหม่ตามรูปแบบอ็อบเจกต์ (JSON) ดังตัวอย่างนี้:

### โครงสร้างข้อมูลคำศัพท์:
```javascript
const vocabData = {
    "ชื่อหมวดหมู่": [
        { 
            hanzi: "อักษรจีน", 
            pinyin: "พินอิน", 
            meaning: "คำแปลภาษาไทย", 
            image: "images/path_to_image.png" // (ใส่รูปภาพเป็นทางเลือกเฉพาะตัวศัพท์ที่มีรูปภาพประกอบ)
        },
        // ต้องใส่ให้ครบ 10 ข้อต่อ 1 หมวดหมู่ เพื่อความลื่นไหลในการแสดงผลโหมดเกม
    ]
};
```

### ตัวอย่างการแก้ไข:
1. **หากต้องการแก้ไขคำแปล**: ค้นหาคำนั้นใน `vocabData` แล้วพิมพ์เปลี่ยนข้อความในช่อง `meaning` หรือ `pinyin` ตามสะดวก
2. **หากต้องการใส่รูปภาพประกอบ**: 
   - นำรูปภาพพิกเซลหรือรูปทั่วไป นามสกุล `.png` หรือ `.jpg` ไปวางไว้ในโฟลเดอร์ `images/`
   - พิมพ์พาธของไฟล์รูปภาพลงในคีย์ `image` ของคำศัพท์ข้อนั้น เช่น `image: "images/my_new_animal.png"` (หากไม่มีรูปภาพให้ลบคีย์ `image` ออกจากข้อนั้น เพื่อให้ระบบแสดงผลตัวหนังสือขนาดใหญ่แทนโดยอัตโนมัติ)

## 🎶 ระบบสังเคราะห์เสียง 8-bit และเอฟเฟกต์ (Audio Synthesis)

จุดเด่นของโปรเจกต์นี้คือ **ไม่ใช้ไฟล์เสียงประกอบภายนอก (.mp3/.wav)** แต่ใช้ **Web Audio API** ในตัวของเบราว์เซอร์ในการสังเคราะห์ขึ้นมาแบบเรียลไทม์ ทำให้แอปพลิเคชันมีขนาดเล็กและโหลดได้รวดเร็วมาก:

1. **ดนตรีประกอบฉาก BGM (Background Music)**:
   - ตรรกะการเล่นอยู่ที่ฟังก์ชัน `playBGM()` ใน [script.js](file:///d:/PtforWork/169/จีน/Flashcard_Chinese/script.js)
   - เล่นโน้ตแบบลูป Chord Progression สี่คอร์ดหลัก `C -> Am -> F -> G` ที่ตัวแปร `bgmNotes` 
   - ใช้คลื่นเสียงทุ้มแบบสามเหลี่ยม (Triangle wave) ในไลน์เบส และคลื่นเสียงใส (Sine wave) ในไลน์เมโลดี้เพื่อให้ไม่รบกวนหูผู้ใช้ขณะอ่านหนังสือ
2. **เสียงเอฟเฟกต์เกม (Sound FX)**:
   - เล่นเสียงผ่านฟังก์ชัน `playQuizSound(type)` มี 3 เสียงหลัก: `'correct'` (เสียงติ๊งประสานระดับสูงสั้น), `'wrong'` (เสียงบัสเบสต่ำสไลด์ลง), และ `'timeout'` (เสียงไซเรนกะแทกเตือน)
   - หากต้องการปรับเปลี่ยนโทนความถี่เสียง สามารถเข้าไปแก้ไขค่าตัวเลขคลื่นความถี่ (Frequency Hz) ในฟังก์ชันนั้นได้โดยตรง

## 🎨 การจัดสไตล์และการจัดการธีม (Styling & Dark Mode)

แอปพลิเคชันออกแบบภายใต้ธีมตู้เกมย้อนยุค (Retro Arcade) โดยดึงฟอนต์พิเศษจาก Google Fonts ได้แก่ **`Press Start 2P`** (ฟอนต์พิกเซลอังกฤษยอดนิยม) และ **`Silkscreen`** ควบคู่กับ **`Noto Sans Thai`** เพื่อให้อ่านภาษาไทยและภาษาจีนได้อย่างสมบูรณ์

- **การปรับแต่งสี (Color Tokens)**: สีพื้นหลักและสีสกินในแอปพลิเคชันจะถูกกำหนดไว้ที่ส่วนบนสุดของไฟล์ [style.css](file:///d:/PtforWork/169/จีน/Flashcard_Chinese/style.css) ด้วย CSS Variables เช่น `--primary-color`, `--card-bg`
- **ระบบธีมมืด (Dark Theme)**: เมื่อผู้เล่นกดปุ่มดวงจันทร์ ระบบจะนำคลาส `.dark-theme` มาครอบที่ตัว `<body>` ซึ่งจะไปทำการทับค่าตัวแปร CSS Variables ให้เป็นโทนสีมืดในระดับสากลโดยอัตโนมัติ

## 🛠️ รายละเอียดการเรียกใช้ปลั๊กอิน (External Libraries)

โปรเจกต์นี้โหลดไลบรารีผ่าน CDN จากภายนอกเพื่อประหยัดพื้นที่เก็บข้อมูล:
1. **HanziWriter** (`hanzi-writer.min.js`): ใช้ในการวาดภาพประกอบลำดับขีด และตรวจจับการลากเขียนเส้นอักษรจีนของนิ้ว/เมาส์ของผู้เล่น
2. **SweetAlert2** (`sweetalert2.all.min.js`): ใช้สร้างกรอบการแจ้งเตือนความสำเร็จและจบเกม โดยเราได้ทำการนำ CSS คลาส `.retro-swal-popup` ไปครอบทับเพื่อให้ขอบและปุ่มเป็นสี่เหลี่ยมเงาบล็อกแนวอาร์เคด
3. **FontAwesome** (`all.min.css`): คลังไอคอนประกอบแผงปุ่มและรายการแถบเมนูในระบบ
